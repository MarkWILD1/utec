# Plan Maestro · Presentación UTEC

Presentación web de 20 diapositivas para la charla *Tecnología, Educación y Emprendimiento* ante estudiantes de UTEC.

## Desarrollo

```bash
npm install
npm run dev
```

## Controles

| Acción | Atajo |
|--------|--------|
| Siguiente | `→` `↓` `Espacio` · scroll · swipe |
| Anterior | `←` `↑` · scroll · swipe |
| Ir al inicio / fin | `Home` / `End` |
| Ir a una diapositiva | Clic en el rail derecho |

La diapositiva **17 — Emprender desde Rivera** tiene una transición más lenta y un tratamiento visual distinto (pico emocional de la charla).

## Build

```bash
npm run build
npm run preview
```
