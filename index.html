Innovación técnica

Deterministic RAG

Una arquitectura creada para Plan Maestro: el contexto no se busca “a ojo” por similitud semántica. Se ensambla antes de llamar al modelo.

  • Grounding explícito
  • Context compiler
  • Auditable y repetible

Los errores me permitieron alcanzar esta solución definitiva.
Misma intención + mismas fuentes = mismo contexto.
Menos alucinaciones. Más control pedagógico.
